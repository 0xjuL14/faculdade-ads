Exeercício 3 - Como funciona o acesso a um site?

Explique, com suas palavras, o que acontece quando uma pessoa digita www.exemplo.com.br no navegador e pressiona Enter. Utilize obrigatoriamente os termos: Navegador; Internet; Servidor; Resposta; Página. Resposta: O usuário digita o site www.exemplo.com.br no navegador. Se tem acesso à internet, o DNS traduz o domínio para um endereço IP, após o navegador envia uma mensagem HTTP para o servidor, que se aprovada, monta dados e devolve o status 200 OK. Como resposta, o navegador recebe os pacotes e o código desenha a página na tela do usuário.
